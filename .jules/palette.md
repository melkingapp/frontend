## 2026-11-03 - Add ARIA attributes to Mobile Menu Header Button
**Learning:** Icon-only buttons used for primary navigation often lack accessible names, hover/focus states, and aria-expanded state which is crucial for screen readers tracking the state of mobile menus.
**Action:** Add localized aria-label, title, focus styles and aria-expanded attribute to icon-only toggles to enhance both keyboard navigation parity and screen reader usability.
