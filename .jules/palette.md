## 2024-10-23 - Add accessibility attributes to mobile menu button
**Learning:** Icon-only buttons in mobile headers often lack screen reader support and proper focus states. Adding localized aria-labels, aria-expanded attributes, and focus-visible utility classes ensures accessibility and keyboard navigation without altering visual design.
**Action:** Always add aria-label, title, aria-expanded, and focus-visible attributes to icon-only interactive elements like mobile menus.
