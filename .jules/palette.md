## 2024-05-18 - Improve keyboard accessibility in header nav icons
**Learning:** Icon-only navigation buttons in global headers lacked visible focus indicators, making them difficult for keyboard users to track where they are. Since the headers have distinct background colors (public, manager, resident), focus colors need to contrast properly against each specific background, but keeping the visual style consistent across the app requires using standard Tailwind focus-visible utilities.
**Action:** Always add `focus-visible:outline-none focus-visible:ring-2` to icon-only navigation elements to ensure keyboard accessibility. Use the appropriate background-contrasting ring color (like `focus-visible:ring-melkingDarkBlue` for light backgrounds and `focus-visible:ring-[#D3B66C]` for dark backgrounds) to make the focus state clearly visible.
