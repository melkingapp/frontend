## 2024-05-16 - Inline IIFE and Chained Array Methods in Render
**Learning:** React components in this codebase frequently use inline Immediately Invoked Function Expressions (IIFEs) or chained array operations (`.filter().some()`, `.filter().length`) directly inside the component body. This is a severe anti-pattern for performance, as it forces the recalculation of derived data and allocates new arrays/objects on every single render.
**Action:** When refactoring React components with heavy inline data processing, replace chained array methods with single-pass `for` loops wrapped in a `useMemo` hook. Avoid completely deleting inline grouping/formatting blocks without verifying if a parent hook's raw data perfectly matches the component's expected data shape. Wrap those formatters in `useMemo` instead to preserve referential equality.
