## 2024-05-18 - Safe React useMemo Refactoring\n**Learning:** When refactoring inline array operations into a `useMemo` hook to optimize performance, do not place the `useMemo` call directly inside the JSX return statement (e.g., `{useMemo(...)}`), as it violates the Rules of Hooks and causes React errors, especially if the surrounding JSX might be conditionally rendered later. \n**Action:** Always declare the `useMemo` hook at the top level of the component body, assign its result to a variable, and then reference that variable inside the JSX.
