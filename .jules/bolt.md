## 2024-05-18 - [Optimize useSelector inline array fallbacks]
**Learning:** When components extract array data from Redux state using `useSelector` with an inline fallback value (e.g., `useSelector(state => state.finance.transactions || [])`), it forces unnecessary component re-renders every time the Redux store updates. The inline `[]` creates a new array reference on each execution, failing the referential equality check, even if the actual transactions remain empty/falsy.
**Action:** Extract the fallback array literal to a module-level constant (e.g., `const EMPTY_ARRAY = []`) and use it in `useSelector`. This ensures stable referential equality and prevents redundant renders without the overhead of `useMemo`. This pattern is highly effective for components observing optional array slices from the Redux store.
