## 2024-05-18 - Filter Loop Refactoring for Performance Optimization
**Learning:** In `src/features/resident/finance/pages/BuildingBalance.jsx` and `src/features/resident/finance/components/BuildingBalanceTable.jsx`, there are expensive array `.filter()` operations being called repeatedly on transaction data inside the React component's main body, leading to synchronous operations blocking the main thread during re-renders. A large `checkFields` array was being dynamically constructed inside `.filter` with a `.some()` loop iterating over it, without wrapping these calculations in a `useMemo` hook. This causes significant performance bottlenecks as the transaction list grows, as it's re-evaluating the whole dataset on every render.
**Action:** Extract large filtering data logic (especially those building dynamic keyword dictionaries or arrays and iterating with nested `.some` loops) into `useMemo` hooks. Also, combine sequential filtering steps into single-pass processing if possible, or heavily cache the resulting arrays to avoid continuous reallocation on every component update. Ensure `useMemo` hooks are declared at the top level of the component.
