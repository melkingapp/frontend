## 2024-05-18 - Optimized Array Operations with useMemo
**Learning:** In React components that render lists (like `ResidentExpenses` and `BuildingBalanceTable`), complex array operations like chaining `.filter()` and `.sort()` directly inside the component body can cause significant performance degradation. These operations are executed on every single render, blocking the main thread, even if the underlying data (`expenses` or `transactions`) hasn't changed.
**Action:** Always wrap derived data calculations that involve iterating over large arrays (like filtering and sorting) in a `useMemo` hook. This ensures the expensive calculations are only performed when their specific dependencies (the data array or the filter/sort criteria) actually change, leading to smoother and faster re-renders.
