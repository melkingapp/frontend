## 2024-05-17 - Prevent Main Thread Blocking By Caching Filtered Arrays
**Learning:** In the `ResidentSidebar.jsx` codebase, there are deeply nested loop operations (grouping values using `forEach`, running `.find()`, and checking `.filter().length`) being called inline during the main render cycle. We must avoid calling expensive array operators directly within React component render functions without caching, as they repeatedly block the main thread and allocate new references.
**Action:** Always extract static mapping operations and derived arrays from raw redux stores (`membershipRequests`) to variables wrapped in `useMemo`, ensuring `const values = useMemo(() => ..., [dependencies])` is used to skip recreation across unnecessary renders while adhering to referential equality expectations.
