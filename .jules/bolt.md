## 2024-05-24 - React.memo on Transaction Row Components
**Learning:** Found an opportunity to optimize rendering performance in large transaction lists by memoizing the `FinanceTableRow` component. Since `FinanceTableRow` is rendered inside `.map()` loops in `BuildingTransactionsView` and `UnitTransactionsView`, and receives primitive props or stable reference props (like functions if passed correctly), it is an excellent candidate for `React.memo()`. This avoids unnecessary re-renders of list items when the parent component re-renders (e.g., when a filter changes, though we should make sure functions don't break memoization).
**Action:** Wrap `FinanceTableRow` component in `React.memo()` to prevent unnecessary re-renders, a standard but critical optimization for large lists.
