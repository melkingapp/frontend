## 2024-10-24 - Memoize derived data in React Components
**Learning:** Found array operations (like `.filter()` and `.map()`) happening on every render in top-level view components like `ManagerBuildingsList` and `BalanceTable`. These operations recalculate lists from Redux store state during every component render cycle, which causes unnecessary performance overhead especially if the source array is large or the component re-renders frequently (e.g. from localized UI updates or parent renders).
**Action:** Always wrap derived data calculations from props or Redux selectors (like filtering a list of transactions or buildings) in `useMemo` hooks. This ensures the calculation only runs when the source data or filter criteria actually change, reducing CPU time during React render cycles.
