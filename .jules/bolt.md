## 2024-05-30 - [Performance Optimization: Centralizing Fallback Arrays]
**Learning:** The codebase heavily uses inline `|| []` as a fallback for Redux selectors or optional props. This recreates a new array reference on every render, which can cause downstream child components wrapped in `React.memo` (or using effects depending on these arrays) to re-render unnecessarily, degrading performance in complex list and table components.
**Action:** Replaced inline `|| []` fallbacks with a stable module-level `const EMPTY_ARRAY = [];` reference across multiple data-heavy components (`BuildingBalanceTable`, `useTransactionsData`, `TransactionsBase`, `PaymentBase`, `RequestBase`, `UnitBase`, `ServicesBase`, `BuildingNewsBase`, `SurveyBase`, etc.) to maintain referential equality and avoid unnecessary allocations/re-renders.
